# Como usar o menu móvel e o lançamento rápido

No celular, toque no botão redondo de menu no canto inferior esquerdo para abrir o painel de navegação. Ele inclui Saldos, Movimentos, Orçamento, Relatórios, Contas, Configurações, Ajuda e sair. Use **Novo movimento** no fim do painel para abrir o lançamento rápido.

## Sugestões de descrição

Ao inserir uma descrição de movimento, as sugestões aparecem depois de digitar pelo menos dois caracteres. Escolha uma descrição anterior correspondente para reutilizá-la ou continue digitando para criar uma nova. Até seis sugestões aparecem acima do campo para que o teclado virtual não as cubra.

## Salvar um movimento

Informe o valor, a descrição, a conta, a categoria e quem fez o gasto; depois salve. Você ainda pode adicionar notas ou outros detalhes quando precisar.
